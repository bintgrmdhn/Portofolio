# Portofolio Bintang Ramadhan

Situs statis (tanpa build). Struktur:

- `index.html` — halaman utama
- `js/` — `three.min.js` (Three.js r149) dan `office3d.js` (pratinjau 360° kantor)
- `assets/profil/` — foto profil, logo, mark
- `assets/feed/` — slide Feed
- `assets/produk/` — foto Produk 1:1
- `assets/brand/` — logo brand
- `assets/banner/` — banner
- `assets/desain/` — hasil desain dan poster
- `assets/mockup/` — mockup
- `assets/3d/` — tekstur kayu dan `render/` (render SketchUp untuk mode Render)
